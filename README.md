# Regine Gabrielle Viola — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. It follows the scrapbook-inspired navy, cream, denim-blue, pink, and yellow visual language of the Canva portfolio.

## Run locally

You can open `index.html` directly in a browser, or start the included Node.js server:

```sh
npm start
```

Then visit <http://localhost:8000>.

## Update content

- Edit the sections and project cards in `index.html`.
- Edit colors, spacing, and responsive behavior in `style.css`.
- Edit the mobile menu and project category filters in `script.js`.
- `server.js` serves the site locally using Node.js built-in modules; no extra packages are needed.
- The portrait in `assets/regine-portrait.png` is cropped from the CV supplied for this portfolio.
